# Changelog

Notable changes to Just Write Some Damn Code are recorded here.

## [0.1.0-alpha.3] — 2026-10-17

- Hide the Windows console window when launching the release app.
- Publish Windows and macOS installers with per-platform SHA-256 checksums.

## [0.1.0-alpha.2] — 2026-10-17

- Add Windows x64 and macOS Apple silicon and Intel installers to GitHub releases.
- Add SHA-256 checksum files for the installers.
- Document download and first-launch steps for the desktop app.

## [0.1.0-alpha.1] — 2026-10-17

First public source alpha.

- Add an editor-first practice workspace with 250 original DSA exercises and 12 single-file build tasks.
- Add Python, JavaScript, TypeScript, and PHP modes with per-language editor preferences and no autocomplete suggestions.
- Save drafts, settings, progress, and passed-exercise history locally.
- Add optional local Ollama exercise variants and qualitative feedback.
- Add a disposable Podman or Docker runner with network access disabled and resource limits.
- Add screenshot documentation and setup instructions for the public repository.

This alpha is source-only. It does not include signed desktop installers, and native packaging and runner behavior still need cross-platform validation.
